# UBG Embed Studio

A static browser app for pasting code or uploading files, previewing the content in a sandboxed iframe, and copying an embeddable iframe snippet.

## Deploy with Vercel

1. Push or confirm this repository on GitHub: `barontingxm1-cell/UBG`.
2. Sign in at https://vercel.com with GitHub.
3. Select **Add New → Project**.
4. Import **barontingxm1-cell/UBG**.
5. Leave the framework preset as **Other** or **Static HTML**.
6. Leave the build command empty and set the output directory to `.` if Vercel asks.
7. Click **Deploy**.

Vercel will give you a public URL such as `ubg-....vercel.app`. Every new push to `main` will redeploy automatically.

This version is frontend-only: uploaded files and saved content stay in the visitor's browser and are not uploaded to a server.
